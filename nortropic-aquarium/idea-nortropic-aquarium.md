# Idea brief: Nortropic Aquarium

## 1. Summary

A future ambient, read-only, TV-castable projection mode on top of Organization OS / Digital Twin / Verkstadsgolvet: the organization observed like an aquarium or ant colony rather than administered via dashboard, under the dual gate TRUE + BEAUTIFUL (later + CURRENT + LEARNING). Load-bearing framing: Aquarium is **never a source of truth or authority surface** — dependency runs REAL CANONICAL STATE → ORGANIZATION OS SEMANTICS → DIGITAL TWIN → AQUARIUM PROJECTION, never reversed — and it is not implemented: PLAN yes, BUILD no.

Source episodes: 1 = `nortropic-aquarium-full-chat.md` ("Skapa Kommunen", msgs 69–79; tags `(← msg N)`); 2 = `nortropic-aquarium-full-chat-CHAT-002.md` (msgs 1–8, 14–17; tags `(← CHAT-002 msg N)`).

## 3. Destination (goal, not implementation plan)

- A calm 2.5D miniature-architectural-diorama world ("Scandinavian product design × management simulation × living ant colony × organizational observability"), a plain read-only web route (`/aquarium`) for browser fullscreen or TV casting.
- Visual grammar: **work is the protagonist** (lineage folios through execution → verification → remediation → publication); avatars only with evidence; **motion is expensive**; **competence looks calm**; boring Stadshuset.
- LIVE owns the present (snapshot + live event cursor, honest staleness); REPLAY owns the story (time compression over real events — an "organizational flight recorder", never simulation).
- Conservation of work; diagnostic overlays (NORMAL/FLOW/AUTHORITY/RISK/…) over a spatially stable map; semantic zoom; DISPLAY-SAFE projection; modes Aquarium/Executive/Operations/Demo off the same truth.
- Co-evolution machinery: Projection Contract, coverage/semantic-drift detection, `NOT YET VISUALIZED` over improvisation, four separately versioned layers, visual comprehension evals.

Choose architecture, decomposition and tooling yourself, within §6.

## 5. Acceptance criteria (v1)

AC1. WHEN any state-bearing motion renders, THE Aquarium SHALL trace it to canonical evidence via a proof path and SHALL never generate fake activity (← CHAT-002 msg 1; msg 70).
AC2. WHEN nothing is happening, THE Aquarium SHALL render calm truthfully — silence is information, never masked by invented activity (← CHAT-002 msg 1; msg 70).
AC3. WHEN a viewer opens LIVE, THE Aquarium SHALL render the snapshot statically and animate only events after the live cursor; on connection loss semantic motion SHALL stop with honest staleness — never simulation (← CHAT-002 msg 4; msg 3).
AC4. WHEN work volume forces aggregation, THE projection SHALL account for exactly the whole canonical quantity — aggregated, never invented or destroyed (← CHAT-002 msg 4; msg 3).
AC5. WHEN Organization OS gains a concept Aquarium cannot express, THE system SHALL detect the coverage gap and render `NOT YET VISUALIZED` rather than improvise (← CHAT-002 msg 6; msg 8).
AC6. WHEN implementation is proposed, THE system SHALL remain blocked until `AQUARIUM_IMPLEMENTATION_READY` passes (OS/Twin readiness, projection boundary, privacy policy, replay contract) (← CHAT-002 msg 14; msg 17).
